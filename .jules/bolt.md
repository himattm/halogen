## 2024-05-24 - Zero-Allocation Hex Color Parsing in Kotlin Multiplatform
**Learning:** In highly called utility functions within Kotlin Multiplatform (like parsing strings to hex colors in a Theme engine), standard library string extension functions (`substring`, `padStart`, `uppercase`, `toString(radix)`) incur significant overhead due to intermediate string allocations and general-purpose parsing state machines.
**Action:** When optimizing hot paths dealing with fixed-format strings (like 7-character hex colors), always replace standard string manipulation with direct bitwise operations, manual character iteration, and pre-allocated `CharArray` mutations. This approach is reliably supported in `commonMain` and can yield a ~5-6x performance boost by eliminating garbage collection pressure.
